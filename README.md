agenc-config
============

Personal configuration for the [AgenC](https://github.com/mieubrisse/agenc) multi-agent orchestration system.

What's here
-----------

- `config.yml` — Declares the agent templates available for missions and the repositories the AgenC daemon keeps synced.
- `claude-modifications/` — Claude Code overrides (instructions and permissions) that AgenC injects into every agent sandbox.
